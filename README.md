# Supermarket Billing System

A simple frontend billing application for a supermarket.

## Features

- Add products with name, quantity, and price
- Apply item-wise discount percentages
- View itemized billing list
- Calculate subtotal, discount total, and grand total
- Remove items from the bill
- Reset or print the bill

## Run locally

1. Open `index.html` in a browser.
2. Or serve the project with a local web server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Files

- `index.html` – markup for the billing UI
- `style.css` – styling for the application
- `script.js` – billing logic and interactions
